# Rhinos Dynasty Command Center

A standalone dynasty fantasy football dashboard for the FFPC Superflex TE-Premium TriFlex Dynasty league. Built for brandont1223 · Rhinos #630.

**Live site:** https://primevalpro.github.io/rhinos-command-center/

---

## What It Does

A single HTML file — no backend, no login, no dependencies beyond Google Fonts. Open it in any browser. It pulls live player values from the FantasyCalc API and player ages from Sleeper automatically on load.

### Tabs
- **League Overview** — full 12-team roster grid with FC-computed floor grades, balance indicators, and expandable detail panels
- **Team Compare** — head-to-head comparison with Matchup View (floor-based) and Roster Construction (ceiling-based)
- **Trade Targets** — Rhinos trade analysis with roster comparison panel and live FC trade calculator
- **Power Rankings** — pre-season (draggable) and mid-season modes, with expandable positional breakdown per team showing FC strength tiers and volatility signals
- **Age & Draft** — championship windows, age profiles, and rookie draft strategy
- **Rosters** — full roster viewer with position filter

### Live Data
- **FantasyCalc API** — player trade values, cached 7 days. Drives all floor grades and trade calculator values.
- **Sleeper API** — player birth dates for accurate ages, cached 30 days.

## Updating the Site

### After trades or waiver moves
1. **Import** → Rosters Only → upload FFPC CSV export
2. **Copy Re-Assess Prompt** → paste into Claude.ai (enable web search) → get JSON back
3. **Import Results** → paste JSON → apply
4. Floor grades and power rankings update automatically
5. **⬇ Download HTML** → rename to `index.html` → push to GitHub

### Pushing to GitHub
1. Go to `github.com/primevalpro/rhinos-command-center`
2. Add file → Upload files → drag `index.html` → Commit changes
3. Live at the URL above in ~1 minute

### During the season (weekly)
1. **Import** → Full Import → upload FFPC CSV → enter current week
2. Power Rankings mid-season mode updates automatically

## How Grades Work

**Floor grades** are computed automatically from FantasyCalc values — never manually set. The engine sums starter FC values per position group across all 12 teams, sorts them, and uses gap detection (~17% drop threshold) to assign S/A/B/C tiers. Overall floor is a weighted composite: QB 30% / RB 20% / WR 20% / TE 15% / Flex 15%.

**Ceiling grades, fragility, windows, philosophy, needs, and surplus** are generated by the re-assess prompt (Claude + web search). Run it after any significant roster change.

**Power Rankings accordion** — click any team row to expand a full positional breakdown. Card border color = FC objective rank (green = top 4, blue = mid, gray = lower-mid, red = bottom 4). UPSIDE ↑ and RISK ↓ badges indicate volatility signals from the re-assess data. Both can appear on the same card — a green card with a RISK badge means "positional strength that's fragile or aging."

## localStorage

Roster imports and re-assess imports are saved to your browser's localStorage automatically. The page remembers your last state on the same device/browser between sessions. localStorage is device-specific — use the Download HTML button to bake the current state into the file and push to GitHub when you want changes visible site-wide.

| Key | Contents |
|-----|---------|
| `rhinos_ktc_values` | FantasyCalc player values |
| `rhinos_ktc_timestamp` | FantasyCalc last fetch time |
| `rhinos_sleeper_ages` | Sleeper birth dates |
| `rhinos_sleeper_timestamp` | Sleeper last fetch time |
| `rhinos_roster_data` | Last imported roster state |
| `rhinos_assess_data` | Last imported re-assess state |
